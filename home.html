    How to improve password security

    • Prefer long, unique passwords or passphrases.
    • Do not reuse passwords across services.
    • Avoid names, dates, keyboard patterns and predictable substitutions.
    • Use a reputable password manager to store unique credentials.
    • Enable multi-factor authentication where available.

    For real accounts, generate and store passwords in a trusted password manager rather than leaving them visible on a shared screen.

    Inspect a suspicious message

    Paste the message and, if available, the sender address. Do not open links or attachments to test them.

    This is a local pattern-based screening aid. It cannot verify the sender, visit or reputation-check links, inspect attachments, or prove a message is safe.

    Warning signs to look for

    • Unexpected urgency, threats or pressure to act immediately.
    • Requests for passwords, PINs, OTPs, BVN or payment details.
    • Sender domains that imitate a known organisation.
    • Shortened, misspelled or unusual web addresses.
    • Unexpected attachments or prizes/refunds that seem too good to be true.

    When in doubt, open the organisation's official app or type its known web address yourself. Contact the organisation using a trusted number.

      How to add the key to an authenticator

      1. Generate a new secret key.
      2. Copy the setup URI or secret key.
      3. In your authenticator app, choose the option to enter a setup key manually.
      4. Use time-based (TOTP) mode, then compare the generated codes.
